A fast, fully static website for **Delhi Public School, Firozabad** — the best CBSE school in Firozabad, Uttar Pradesh. Built from **publicly available sources only**; no private personal information of students or staff is published.

## Run locally

No build step required — it's plain HTML/CSS/JS.

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
